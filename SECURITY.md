# Security Policy

PrivacyGuard is a defensive, local-first security monitoring project.

## Reporting a security issue

Please avoid publishing sensitive vulnerability details in a public issue. If this repository is public and a private reporting channel is not configured, open a minimal issue asking for a private contact method without including exploit details.

## Scope and safety

PrivacyGuard restricts scanning to the automatically detected private local network and a controlled set of ports. The project does not treat an open service as proof of a vulnerability.
